# cs400-P3-NetworkDesign-CEBuilding
This repository contains the network design for the new USP Civil Engineering Building (CS400 IEP, S2 2026). A 3-tier hierarchy (core/distribution/access) across 4 levels, 12 role-based VLANs within inter-VLAN ACLs, building-wide Wi-Fi, CCTV and biometric segments, and a rooftop server room, simulated in GNS3.
